#Survival Prediction

The objective was to predict whether a passenger would survive based on information available in the Titanic dataset. I analyzed factors such as age, gender, passenger class, and fare to identify patterns related to survival.

I used Python-based data analysis tools such as Pandas and NumPy and trained a Logistic Regression model for prediction.

Through this project, I gained experience in working with datasets, analyzing features, and understanding how machine learning models can be used for predictive problems.
